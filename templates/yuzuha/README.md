Bot do [Fluxer](https://fluxer.app) com [Yuzuha](https://github.com/horizzon3507/yuzuha).

## Começar

```sh
npm install
npm run check
npm run typecheck
npm test
cp .env.example .env
```

Preencha `FLUXER_BOT_TOKEN` no `.env` e inicie o bot:

```sh
npm run dev
```

Comandos de exemplo em `commands/`: `ping` e `eco`.
